## 🗂 XML 파일 구조

```
<HWPML Version="2.91">          ← 루트 태그 (HWP 변환 포맷)
  <BODY>
    <SECTION Id="0">             ← 섹션 (문서 전체가 1개 섹션)
      <P ParaShape="ID" Style="0">         ← 단락 (문단)
        <TEXT CharShape="ID">              ← 텍스트 블록
          <CHAR>실제 텍스트 내용</CHAR>   ← 본문 텍스트
          <TAB/>                           ← 탭 문자
          <TABLE>...</TABLE>               ← 표 삽입
          <MARKPENBEGIN Color="색상코드"/> ← 형광펜 시작
          <MARKPENEND/>                    ← 형광펜 끝
          <PAGENUM/>                       ← 페이지 번호
          <NEWNUM/>                        ← 페이지 번호 재설정
          <PAGEHIDING/>                    ← 페이지 번호 숨김
        </TEXT>
      </P>
    </SECTION>
  </BODY>
</HWPML>
```

## 🎨 XSL 파일 구조 (서식 정의)

XSL은 **HTML/CSS 방식**으로 서식을 정의합니다.
XML의 ID → XSL의 CSS 정의로 매핑됩니다.

### 단락 서식 (ParaShape ID → P#ID)

```css
P#863 {
  text-align: Justify;
  /* 관(款) 제목용 단락 서식 */
}

P#861 {
  text-align: Justify;
  /* 조(條) 본문용 단락 서식 */
}

P#20 {
  text-align: Center;
  /* 가운데 정렬 단락 */
}
```

### 글자 서식 (CharShape ID → SPAN#ID)

```css
SPAN#28 {
  font-family: 굴림;
  font-size: 13.3px;
  font-weight: bold;    /* 굵은 글씨 — 관 제목, 목차 등 */
}

SPAN#14 {
  font-family: 굴림;
  font-size: 13.3px;    /* 일반 글씨 — 조문 본문 */
}

SPAN#77 {
  font-family: 굴림;
  font-size: 18.7px;
  font-weight: bold;    /* 큰 굵은 글씨 — 대제목 */
}
```

### 표 서식 (TABLE#InstId)

```css
TABLE#1461608767 {
  width: 536.3px;
  border-collapse: collapse;
}
TABLE#1461608767 TR#1 TD#1 {
  border-top-style: SlimThick;    /* 표 상단 이중선 */
  border-bottom-style: ThickSlim; /* 표 하단 이중선 */
}
```

## 📋 약관 조항 계층 구조

### 보통약관 계층

| 계층 | 예시 | ParaShape | CharShape | 특이사항 |
|------|------|-----------|-----------|----------|
| 관(款) 제목 | 제1관 목적 및 용어의 정의 | 863 | 28 (굵음) | 일반 단락 |
| 조(條) 제목 | 제1조(목적) | 861 | 14 (일반) | 일반 단락 |
| 항/호 본문 | ① 이 약관은... | 861 | 14 (일반) | 일반 단락 |

### 특약 계층 (보통약관과 구조 다름 ⚠️)

| 계층 | 예시 | ParaShape | CharShape | 특이사항 |
|------|------|-----------|-----------|----------|
| 장(章) 제목 | 제1장. 상해관련 특별약관 | 20 | 48 | **TABLE 안에 포함됨** |
| 특약명(대) | 1. 일반상해입원비(1일-180일) 특별약관 | 5 | 36 | TABLE 안에 포함됨 |
| 특약명(소) | 1-1. 일반상해입원비(경증간편가입Ⅲ) 특별약관 | 5 | 9/8 | TABLE 안에 포함됨 |
| 조(條) 제목 | 제1조(보험금의 지급사유) | 5 | 56 | 일반 단락 |
| 본문 | 회사는 피보험자에게... | 89 | 59 | 일반 단락 |

### 특약 장(章) 구성 (목차 기준)

| 장 | 내용 | XML 라인(약) |
|----|------|-------------|
| 제1장 | 상해관련 특별약관 | 9,731 |
| 제2장 | 질병관련 특별약관 | 12,500 |
| 제3장 | 상해 및 질병관련 특별약관 | 37,519 |
| 제4장 | 제도성 특별약관 | 38,437 |

> ⚠️ **핵심 차이점**
> - 보통약관: 관(款) → 조(條) / 일반 단락 구조
> - 특약: 장(章) → 특약명 → 조(條) / **장·특약명은 TABLE 태그 안에 포함**
>
> 조항 선별 시 텍스트 패턴(제N장, N-N. XXX 특별약관) + TABLE 구조를 함께 활용해야 함.

## 📊 엑셀 조건표 연계 구조

파일: `data/(조건표)L3912~L3913_다렉3.5.5(26.04).xlsx` — sheet2 (`다렉3.5.5간편종합_2종`)

### 주요 컬럼

| 컬럼 | 내용 | 예시 |
|------|------|------|
| 목차명 | XML에서 찾을 텍스트 (매핑 키) | `1-1. 일반상해입원비(1일-180일)(경증간편가입Ⅲ) 특별약관` |
| **담보코드** | **맞춤약관 KEY** | `LK501G` |
| 상품코드 | 어느 상품인지 | `L3912` |
| 분류기준 | 계층 구분 | 대/중/소 |

### 담보코드 규칙

| 담보코드 | 의미 |
|----------|------|
| `L00000` | 공통 항목 — 보통약관·가이드북·Ⅰ~Ⅵ·제4장 제도성 특약 → **항상 포함** |
| `LK501G` 등 | 개별 특약 — 가입자마다 다름 → **가입 여부로 포함/삭제 결정** |

### 삭제 알고리즘 요약

```
삭제 대상 = 전체 특약 − L00000(공통) − 가입자 담보코드(가입 특약)
```

> ⚠️ `<INDEXMARK>` 태그는 19개뿐으로 전체 특약(70개+)을 커버하지 못함
> → KEY 매핑은 엑셀 조건표의 목차명을 기준으로 XML 텍스트와 매칭
