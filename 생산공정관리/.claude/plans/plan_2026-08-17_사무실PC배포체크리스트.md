## DB 마이그레이션 (`python scripts/init_db_mariadb.py` 1회 실행으로 전부 처리됨)

1. `단가마스터.인쇄면 ENUM('단면','양면') DEFAULT '양면'` 신규 컬럼
2. (참고용, 이미 로컬에서 실행 완료된 1회성 SQL — 사무실 PC에서도 별도로 실행 필요)
   `단가마스터_자재단가`·`단가마스터_자재단가_매칭`에 한국예탁결제원(자재코드 1435 "무창대봉투",
   120원)·KB증권(자재코드 414 "E)KB증권 거래원장 각대봉투", 130원) 데이터 이관 — 로컬에서 실행한
   INSERT문 재현 필요(정확한 값은 `docs/CHANGELOG.md` 2026-08-17 "봉입자재비 자재단가 이관" 항목 참고)

## 배포 후 확인할 것

- 현대해상 97509 미리보기 — 봉입자재비(자재97) 50원 분리 확인
- 한국예탁결제원·KB증권 — 각대대봉투 자재단가 이관 후 청구 금액이 이관 전과 동일한지 확인
- 아무 거래처 단가 수정 화면 — "인쇄면" 드롭다운 정상 노출 확인
- 출력비·봉입비가 자재사용량 기준으로 바뀌어 **실제 청구 금액이 달라지는 거래처가 있을 수 있음**
  (로컬 회귀 검증에서 27개 조합이 의도적으로 달라짐 확인됨 — 강남대성수능연구소·KB국민카드·
