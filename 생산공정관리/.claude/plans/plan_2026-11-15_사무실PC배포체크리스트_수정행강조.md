# 사무실 PC 배포 체크리스트: 비교 창 "사람이 고친 행" 강조

> 상위 계획: `.claude/plans/plan_비교창_수정행강조.md`
> 상태: ⛔ **쓰지 않음** — `plan_2026-11-15_사무실PC배포체크리스트_비교창개선.md`(통합 묶음 `배포_20261115_비교창개선`)로 대체 (2026-11-15)
> 소요 시간: 약 15~20분(화면 조립 시간 포함), **DB 변경 없음**(마이그레이션 실행 안 함)

## 이번 배포로 바뀌는 것
- 발행요청목록·발행완료·수정이력 탭에서 배지(편집됨/원본)를 누르면 비교 창이 열립니다. 이 창에서 사람이 직접 고친 행이 색으로 표시됩니다.
  - **노란 행**: 고친 행입니다. 바뀐 칸은 빨간 굵은 글씨로 보이고, 옆에 이전 값이 붙습니다. 예: `330 (320)`
  - **초록 행 + `추가`**: 사람이 새로 넣은 행입니다.
  - **왼쪽 원본의 회색 취소선 + `삭제`**: 최종에서 빠진 행입니다.
- 2026-08-18 이전에 발행된 건은 표시 대신 "지원하지 않습니다" 안내가 나옵니다.

---

## 0단계 — 준비물
- [ ] 로컬 PC의 `output\배포_20261115_수정행강조` 폴더(약 1.5MB)를 USB에 통째로 복사합니다.
  - 들어 있는 것: `scripts\api.py`, `frontend`, `API서버_재시작_사무실PC.bat`, 이 체크리스트
  - 빠져 있는 것: `.env.local`, `node_modules`, `.next`

## 1단계 — 서버 백업·복사
- [ ] 사무실 PC의 `scripts\api.py`를 복사해 **`api.py.bak_20261115_강조`**라는 이름으로 둡니다.
  - 오늘 앞서 만든 `bak_20261115b`·`c` 백업을 덮어쓰지 않으려고 이름을 따로 붙였습니다.
- [ ] USB의 `scripts\api.py`로 **덮어씁니다.**
  - ❗ `db_config.py`는 복사하지 않습니다.

## 2단계 — API 서버 재시작
- [ ] `API서버_재시작_사무실PC.bat`을 더블클릭합니다. (사무실 PC에 이미 있습니다)
  - "종료 완료"나 "건너뜀"이 나온 뒤 새로 시작하면 정상입니다.
- [ ] 브라우저에서 `http://localhost:8001/health`를 열어 `"status":"ok"`가 나오는지 확인합니다.

## 3단계 — 화면(frontend) 반영 (B안)
- [ ] 웹 화면 창(포트 3000의 검은 창)을 **먼저 닫습니다.**
- [ ] 사무실 PC의 `frontend` 폴더 이름을 **`frontend_old_20261115_강조`**로 바꿉니다.
  - 오늘 앞서 만든 `frontend_old_20261115`가 이미 있으므로 이름을 다르게 붙입니다.
- [ ] USB의 `frontend` 폴더를 프로젝트 폴더에 붙여 넣습니다.
- [ ] `frontend_old_20261115_강조\.env.local`을 새 `frontend`에 **복사**합니다.
  - 파일이 안 보이면 탐색기에서 [보기] → [표시] → [숨긴 항목]을 체크합니다.
- [ ] (확인) 새 `frontend` 안에 `.env.local`이 있는지 봅니다.
- [ ] `웹화면_업데이트_사무실PC.bat`을 더블클릭합니다. [1]~[4]단계가 끝난 뒤 `Ready` 문구가 나오는지 봅니다.
  - ❗ [2단계] 패키지 설치가 실패하면 `frontend_old_20261115_강조\node_modules`를 새 `frontend`에 복사한 뒤 bat을 다시 실행합니다.

## 4단계 — 화면 확인 (`http://192.168.30.201:3000`)
- [ ] **발행요청목록**에서 **D-202611-00008**의 배지를 클릭합니다.
  - 오른쪽 표의 "용지 제작비" 행이 노란색인지 봅니다.
  - 수량 `330 (320)`, 금액 `4,950 (4,800)`이 빨간 굵은 글씨인지 봅니다.
- [ ] 같은 창에서 나머지 행(출력비·봉입비·추가봉입비)은 색이 없는지 봅니다.
  - 위쪽 "수정이력"을 펼쳐, 적힌 항목과 강조된 칸이 일치하는지 봅니다.
  - 설명 문구 아래에 범례 한 줄이 보이는지 봅니다.
- [ ] 2026-08-18 이전에 발행된 건이 있으면 배지를 눌러 봅니다. (예: 08월 초 D-202608-000xx)
  - "2026-08-18 이전에 발행되어 수정된 행 표시를 지원하지 않습니다" 안내가 나오는지 봅니다.
  - 로컬 PC에는 이런 건이 없어 여기서 처음 확인하는 항목입니다.

## 문제가 생기면 (되돌리기)
| 증상 | 조치 |
|---|---|
| 2단계 이후 API 서버가 안 켜짐 | `api.py.bak_20261115_강조`를 `api.py`로 되돌린 뒤 재시작 bat을 실행합니다. |
| 3단계 이후 화면 오류 | 화면 창을 닫습니다. → 새 `frontend`를 `frontend_failed_20261115_강조`로 이름을 바꿉니다. → `frontend_old_20261115_강조`를 `frontend`로 되돌립니다. → `웹화면_실행_사무실PC.bat`을 실행합니다. |

- **새 서버와 예전 화면 조합도 동작합니다.** 예전 화면은 새 꼬리표 값을 무시하고 지금처럼 보여 줍니다. 그래서 화면만 되돌려도 됩니다.
