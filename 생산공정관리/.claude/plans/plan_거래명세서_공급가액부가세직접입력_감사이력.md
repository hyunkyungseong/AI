## 2026-08-14 후속 수정 (실사용 화면 확인 중 발견)
- 조정 입력칸이 `type="number"` 빈값+placeholder 방식이라 위/아래 화살표가 -1로 튀고 전체를
  다시 입력해야 하던 문제 — 수량·단가·금액 칸과 동일한 `type="text"`+천단위 콤마 왕복 변환 방식으로
  통일, 항상 실제 값이 편집 가능한 상태로 미리 채워지도록 변경
- 품목별 수정이력을 "품목목록 N건→M건" 요약 대신 **항목별 상세**(`전산출력비(수량)` 등)로 확장 —
  `_품목_변경_이력()` 신규(코드·표시품명 키 매칭, 값 변경/추가/삭제 구분)
- **diff 기준선을 "자동계산 원본" → "조건식 적용 후 청구명세서"로 변경** — 저장된 조건식이 자동으로
  이름을 바꿔둔 상태에서 사람이 값 하나만 고쳐도 "여러 품목 삭제+추가"로 지저분하게 기록되던 문제
  해결(스크린샷으로 실제 확인). 종단 테스트로 "미분류(조건식 안 걸린) 원본 항목이 오탐되는" 사각지대도
  추가 발견·수정
- **"편집됨" 배지와 부분취소 게이트 분리** — 편집여부(부분취소 게이트)는 안전을 위해 원본 기준
  그대로 유지, 배지만 "실제 감사이력 있음"(`수정이력있음`, 신규)으로 분리. 조건식을 쓰는 거래처는
  확정마다 편집여부=1이 되어 부분취소가 사실상 항상 막혀있었다는 사실도 이번에 함께 확인(기존
  동작, 오늘 작업과 무관 — 부분취소 자체 개선은 별도 과제로 분리)
- "수정이력" 탭이 확정 직후 새로고침 없이는 새 내역을 못 보여주던 문제 — SKILL-34 패턴(비활성→
  활성 전환 시 재조회)을 `Tab4EditHistory.tsx`에도 적용
- 수정이력 표 "필드" 칸 표기를 "품목명(필드명)" 한 칸으로 통일(`frontend/lib/auditLog.ts` 신규)

## 요청 배경
마케팅팀 요청: 발행 전(미리보기·확정 단계) 화면에서 자동계산된 공급가액·부가세를 원단위 절사·반올림
차이 보정 목적으로 직접 입력해 최종 숫자로 덮어쓸 수 있어야 함. 조가 여러 개라 은행별 등으로 엑셀
시트가 여러 장 나오는 거래명세서(BC카드 사례처럼 조 6개)는 개별 조 시트가 아니라 맨 앞 "통합시트"의
공급가액·부가세·합계만 조정하면 된다고 사용자 확인. 이어서 "DB 스키마를 건드리는 김에" 이 총계
조정뿐 아니라 기존에도 가능했던 수량·단가·금액 항목별 수정까지 포함해 "누가/언제 무엇을 바꿨는지"
남는 정식 감사이력(audit log)도 함께 요청받음.

## 조사로 발견한 기존 버그 2건(이번에 함께 수정)
1. 다운로드 시점(`_거래명세서_엑셀_시트목록()`)이 DB에 저장된 `거래명세서.공급가액/세액/합계`를
   전혀 안 읽고 매번 `거래명세서_품목`(구분='최종') 라인아이템을 재합산해 재계산하고 있었음 —
   override가 실제로 효과를 내려면 이 다운로드 경로 자체를 고쳐야 했음.
2. `Tab4Invoice.tsx`의 확정 저장 로직이 부가세 "포함" 거래처에서 미리보기 화면의 총액÷11 역산
   분리(`billing.부가세_표시분리()`, 2026-08-12 도입)를 안 쓰고 세액=0·공급가액=원시합계로 저장하고
   있어, 화면에 보이던 값과 실제 저장값이 이미 어긋나 있었음.

## 구현 내용
- **DB**: `거래명세서.공급가액_직접입력`·`세액_직접입력`(nullable DECIMAL) 2컬럼 + `거래명세서_수정이력`
  신규 테이블(필드명·이전값·이후값·비고·수정자·수정일시)
- **백엔드**(`scripts/api.py`): `거래명세서요청()`가 로그인 사용자명을 받아 감사이력 수정자로 기록,
  override 검증(통합시트명 트리밍과 동일 패턴), 편집여부 판정에 총계 override 포함(부분취소 차단
  보호 자동 적용), `_거래명세서_엑셀_시트목록()`이 단일/통합 시트에만 override 반영(개별 조 시트는
  항상 자동계산), `거래명세서품목이력()` 확장 + 신규 `GET /거래명세서수정이력`
- **프론트엔드**: `InvoicePreviewDialog.tsx`(조정 입력칸), `Tab4Invoice.tsx`(포함 거래처 버그 수정 +
  override 전달), `InvoiceHistoryDialog.tsx`(감사이력 표), 신규 `Tab4EditHistory.tsx`("수정이력"
  하위탭, 전체 조회) + `Dashboard.tsx`/`Tab4.tsx` 서브탭 연결
