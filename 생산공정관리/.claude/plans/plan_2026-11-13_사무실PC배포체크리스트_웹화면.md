# 사무실 PC 배포 체크리스트 — 웹 화면(Next.js) 자체 호스팅 (6단계 [B])

> 상위 계획: `plan_6단계_사무실PC자체호스팅.md`
> 목표: 직원 PC에서 `http://192.168.30.201:3000` 접속 → 로그인 → 탭 5개 사용
> 사무실 PC 인터넷: UTM 웹필터 — `registry.npmjs.org`·`fonts.googleapis.com`·`fonts.gstatic.com` 3개 등록·접속 확인 완료(2026-11-13)

## B1. Node.js 24 설치
- [x] (다른 PC에서) nodejs.org 다운로드 페이지 → 버전 **v24.22.3 (LTS)** 선택 → 아래로 스크롤 → Windows 설치 프로그램(.msi) **x64** 받기 → USB로 옮김
  - v26은 고르지 않음(로컬 PC v24.14.0과 같은 24 계열로 맞춤)
- [x] 설치 파일 실행 → 옵션은 모두 기본값으로 "Next" → 설치 완료
- [x] **새로** 연 명령 프롬프트(cmd)에 `node -v` 입력 → `v24.`으로 시작하면 성공
  - ❗ "인식할 수 없는 명령"이 나오면: cmd 창을 닫고 새로 열기 → 그래도 안 되면 PC 재부팅 후 다시 확인
- [x] 같은 cmd에 `npm ping` 입력 → `PONG` 비슷한 문구가 나오면 패키지 저장소 연결 정상

## B2. 파일 복사 (로컬 PC → 사무실 PC 프로젝트 폴더, API 서버가 있는 그 폴더)
- [x] `frontend` 폴더 통째로 복사 — 단, 아래 3개는 **빼고** 복사
  - `frontend\node_modules` (용량 큼, 사무실 PC에서 새로 설치됨)
  - `frontend\.next` (조립 결과물, 사무실 PC에서 새로 만듦)
  - `frontend\.env.local` (로컬 PC용 주소가 들어있음 — 사무실 PC용은 B3에서 새로 작성)
- [x] `웹화면_업데이트_사무실PC.bat`, `웹화면_실행_사무실PC.bat` 2개를 프로젝트 맨 위 폴더(`frontend` 폴더와 같은 위치)에 복사

## B3. 사무실 PC용 설정 파일 작성
- [x] 메모장을 열어 아래 한 줄만 입력
  ```
  FASTAPI_URL=http://127.0.0.1:8001
  ```
- [x] "다른 이름으로 저장" → 위치 `frontend` 폴더, 파일 형식 **모든 파일(*.*)**, 파일 이름 `.env.local`
  - ❗ 형식을 "텍스트 문서"로 두면 `.env.local.txt`로 저장돼 인식 안 됨

## B4. 포트 3000 사용 여부 확인 (8000번 "ibx dashboard" 전례)
- [x] cmd에 `netstat -ano | findstr :3000` 입력
  - 아무것도 안 나오면 → 비어있음, 다음 단계로
  - `LISTENING` 줄이 나오면 → **진행 멈추고 Claude에게 화면 캡처 전달**(다른 포트로 우회 결정 필요)

## B5. API 서버 켜져 있는지 확인
- [x] 사무실 PC 브라우저에서 `http://localhost:8001/health` → 정상 응답 확인 (안 되면 `API서버_실행_사무실PC.bat` 먼저 실행)

## B6. 웹 화면 설치·실행
- [x] `웹화면_업데이트_사무실PC.bat` 더블클릭 → [1]~[4]단계 진행(처음엔 수 분 소요)
- [x] 창에 `Ready` 비슷한 문구가 뜨면 사무실 PC 브라우저에서 `http://localhost:3000` 접속 확인
  - ❗ 도중에 "[오류]"로 멈추면 그 창 화면을 캡처해 전달
- [x] 이때 "Windows 보안 경고(방화벽)" 창이 뜨면 **"액세스 허용"** 클릭

## B7. 방화벽 포트 3000 열기 (직원 PC 접속용)
- [x] 시작 메뉴에서 "cmd" 검색 → 마우스 오른쪽 → **관리자 권한으로 실행**
- [x] 아래 명령 붙여넣기 → "확인되었습니다" 메시지 확인
  ```
  netsh advfirewall firewall add rule name="생산공정관리 웹화면 3000" dir=in action=allow protocol=TCP localport=3000
  ```
  - 참고: API 서버(8001)는 같은 PC 안의 웹 화면만 부르므로 직원용으로 따로 열 필요 없음

## B8. 직원 PC 최종 확인
- [x] **다른 직원 PC** 브라우저에서 `http://192.168.30.201:3000` 접속
- [x] 로그인 → 탭 5개 차례로 클릭 → 로그인 화면으로 튕기지 않고 데이터 나오면 완료
  - ❗ 접속 자체가 안 되면: B7 방화벽 규칙 다시 확인 / 사무실 PC에서 웹 화면 창이 켜져 있는지 확인

## 평소 운영
- 사무실 PC를 껐다 켠 뒤: `API서버_실행_사무실PC.bat` → `웹화면_실행_사무실PC.bat` 순서로 실행(창 2개는 닫지 말 것)
- 화면 수정본 반영: `frontend` 폴더 복사(B2와 같은 3개 제외) → `웹화면_업데이트_사무실PC.bat`
