# 2026-08-24(후속) 버그 수정 3건 사무실 PC 배포 체크리스트

> 상태: ✅ 배포 완료(2026-08-25) — 1번(공정단가 수정 화면 오류) 사용자 브라우저 확인 완료.
> 2번(장수·봉입건수 경고)·3번(공정단가 비고 표시)은 사용자 확인 대기 중.

> 이번 배포는 **코드 파일 2개만 복사하면 끝**입니다. DB 구조 변경(마이그레이션)이 없습니다 —
> 아래 세 가지 모두 이미 있는 컬럼·테이블만 사용합니다.

## 오늘(후속 세션) 작업 요약
1. **공정단가 수정 화면 오류 수정** — 이미 등록된 공정단가(무광코팅비·제본비 등)를 "수정"으로 열 때
   브라우저 콘솔에 "duplicate key" 오류가 나던 문제 (`frontend/components/PricingProcessSection.tsx`,
   **프론트엔드 전용 — 사무실 PC 배포 대상 아님**)
2. **"장수·봉입건수 불일치" 오탐 경고 수정** — 책 제작류(제본 등 신규공정, 봉투를 안 쓰는 작업)에서
   실제로는 문제없는데도 "봉투 자재이력 없음" 경고가 잘못 뜨던 문제 (`scripts/billing.py`)
3. **공정단가 "비고" 미리보기 표시** — 공정단가 등록 시 입력한 비고가 거래명세서 미리보기 왼쪽
   원본 표에도 함께 보이도록 신규 반영 (`scripts/api.py`, `scripts/billing.py` — DB는 기존
   `단가마스터_공정단가.비고` 컬럼을 그대로 읽기만 함, 신규 컬럼 아님)

---

## 1단계 — 코드 파일 복사
로컬 PC의 아래 2개 파일을 사무실 PC의 같은 경로(`scripts/`)로 덮어씁니다.

- `scripts/api.py`
- `scripts/billing.py`

**`init_db_mariadb.py` 실행(마이그레이션)은 이번엔 필요 없습니다** — 위 세 건 모두 기존 컬럼·테이블만
사용합니다. **프론트엔드 파일도 복사할 필요 없습니다** — 화면(1번 항목 포함)은 로컬 PC의 Next.js가
그대로 담당하고, `frontend/.env.local`의 `FASTAPI_URL`로 사무실 PC를 가리켜 씁니다.

## 2단계 — API 서버 재시작
1. 기존에 떠 있는 API 서버 창을 닫거나 Ctrl+C로 종료(포트 8001)
2. `API서버_실행_사무실PC.bat` 다시 실행
3. 브라우저에서 `http://localhost:8001/health` 접속 → 정상 응답 확인

여기까지 하면 배포 끝입니다.

---

## 배포 후 확인할 것 (브라우저)
1. 단가마스터에서 이미 등록된 공정단가(예: 무광코팅비) "수정" 클릭 → 개발자도구 콘솔(F12)에
   빨간색 "duplicate key" 오류가 더 이상 안 떠야 함
2. 책 제작류(제본·무광코팅 등 신규공정) 거래처의 의뢰서로 "거래명세서 요청" 미리보기를 열었을 때,
   봉투를 원래 안 쓰는 작업이면 "장수·봉입건수" 노란 경고 배너가 더 이상 안 보여야 함(반대로 실제
   봉투를 쓰는 일반 거래처는 지금처럼 필요할 때 그대로 경고가 떠야 함 — 회귀 없음)
3. 공정단가에 비고를 입력해둔 거래처(예: 강남대성수능연구소)로 미리보기를 열면, 왼쪽 원본 표의
   해당 품목명 옆에 그 비고가 파란 글씨로(자재명과 같은 자리) 표시돼야 함

❌ 오류 시: 빨간색 오류 메시지를 캡처하거나 내용을 그대로 복사해서 알려주세요.
