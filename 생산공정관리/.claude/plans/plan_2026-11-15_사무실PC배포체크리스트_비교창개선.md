## 이번 배포로 바뀌는 것
1. **비교 창에서 사람이 고친 행이 색으로 보입니다.**
   - 비교 창은 발행요청목록·발행완료·수정이력 탭에서 배지를 누르면 열립니다.
   - **노란 행**: 고친 행입니다. 바뀐 칸은 빨간 굵은 글씨로 보이고, 옆에 이전 값이 붙습니다. 예: `330 (320)`
   - **초록 행 + `추가`**: 사람이 새로 넣은 행입니다.
   - **왼쪽 원본의 회색 취소선 + `삭제`**: 최종에서 빠진 행입니다.
   - 2026-08-18 이전에 발행된 건은 "지원하지 않습니다"라는 안내만 나옵니다.
2. **팝업 창 7종을 제목줄로 끌어서 옮길 수 있습니다.**
   - 대상: 미리보기, 비교, 확인(취소 사유), 거래처, 단가, 비밀번호 변경, 계정 관리 작은 창
   - 제목줄을 더블클릭하면 가운데로 돌아옵니다.
   - 창을 닫았다 다시 열면 가운데에서 열립니다.

## 문제가 생기면 (되돌리기)
| 증상 | 조치 |
|---|---|
| 2단계 이후 API 서버가 안 켜짐 | `api.py.bak_20261115_비교창`을 `api.py`로 되돌린 뒤 재시작 bat을 실행합니다. |
| 3단계 이후 화면 오류 | 화면 창을 닫습니다. → 새 `frontend`를 `frontend_failed_20261115_비교창`으로 이름을 바꿉니다. → `frontend_old_20261115_비교창`을 `frontend`로 되돌립니다. → `웹화면_실행_사무실PC.bat`을 실행합니다. |

- **새 서버와 예전 화면 조합도 동작합니다.** 예전 화면은 새 꼬리표 값을 무시합니다. 그래서 화면만 되돌려도 됩니다.
  - 이 경우 요청 1·2의 화면 변화가 함께 사라집니다.
