> 상위 계획: `.claude/plans/bug_부분취소_원본허용.md`
> 상태: ⛔ 사용 안 함 — 취소 화면 개선과 통합 배포로 대체(`plan_2026-11-15_사무실PC배포체크리스트_취소화면.md`, 묶음 `output/배포_20261115_취소화면`)
> 소요 시간: 약 5분 — **서버 파일 1개, DB·화면 변경 없음** (웹 화면 재시작 불필요, 로그인 유지)

## 이번 배포로 바뀌는 것
1. **"원본"(조건식 결과 그대로, 사람이 안 고친) 거래명세서도 부분취소 가능** — 예: D-202611-00003
2. 부분취소하면 남은 의뢰서로 **품목까지 다시 만들어 저장** → 엑셀에 취소한 의뢰서 금액이 남지 않음, 구분자 행·비고는 유지
3. "포함" 거래처 부분취소 후 **세액이 0이 아니라 합계÷11로** 저장 → 엑셀 표지 세액 정상
4. 취소·발행취소(되돌리기)만 한 건은 배지가 **"원본" 그대로**
5. 막히는 경우 안내 문구 변경
   - 사람이 금액·품목을 고친 건(편집됨): "금액·품목을 수정한 거래명세서(편집됨)는 부분취소할 수 없습니다. 전체 의뢰서를 선택해 전체취소한 뒤, 남길 의뢰서만 다시 거래명세서 요청해 주세요."
   - 업무명 하나가 통째로 빠져 통합조건식이 안 맞는 경우: "취소 후 남는 업무명(…)에 맞는 조건식이 없습니다(기존 조건식: …). …"

- [ ] 사무실 PC `scripts\api.py` → `api.py.bak_20261115b` (오늘 앞 배포 백업 `.bak_20261115`와 구분)

## 2단계 — 복사
- [ ] USB `배포_20261115_부분취소\scripts\api.py`를 사무실 PC `scripts`에 덮어쓰기 (`db_config.py`는 복사 금지)

## 3단계 — API 서버 재시작
- [ ] `API서버_재시작_사무실PC.bat` 더블클릭 → `Application startup complete.` 확인(창은 닫지 않기)
- [ ] `http://localhost:8001/health` → `"status":"ok"`
- 웹 화면은 재시작 불필요 — 열린 화면은 F5(새로고침)만

## 4단계 — 화면 확인 (`http://192.168.30.201:3000` → 거래명세서 관리 → 발행요청목록)
- [ ] **"원본"** 거래명세서(예: D-202611-00003)에서 의뢰서 1건만 체크 → [취소 (선택한 의뢰서만)] → **성공**, 배지 "원본" 그대로
- [ ] 그 건의 확정공급가액이 남은 의뢰서 기준으로 줄었는지, 엑셀 다운로드 시 취소한 의뢰서 금액이 시트에 없고 표지(요청내용) 세액이 0이 아닌지
- [ ] **"편집됨"** 건(예: D-202608-00081)에서 일부만 취소 → 새 안내 문구로 막히는지
