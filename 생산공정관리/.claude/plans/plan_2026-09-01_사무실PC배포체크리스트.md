# 2026-09-01 사무실 PC 배포 체크리스트

> 상태: ✅ 배포 완료(2026-09-01) — 사용자 브라우저 확인 완료. 로컬·사무실 PC 코드·DB 동기화 상태,
> 남은 미배포 항목 없음.
> 상세 배경: `.claude/plans/bb-ab-vast-piglet.md`

## 오늘 수정 내용 요약

1. **거래명세서 원본 표 합산 로직에 업무명 구분 키 추가** — 서로 다른 업무명이 같은 작업명을 쓰면
   BB/AB 등 품목 수량·금액이 조용히 한 줄로 합쳐지던 버그 수정 + 조건식에 "업무명" 필드 노출
2. **"편집됨" 오탐 버그 수정** — 소수 단가(예: 16.8원) 품목이 섞이면 아무것도 안 고쳤는데도
   "공급가액"·"합계" 수정이력이 잘못 남던 문제
3. **"장수/자재사용량 불일치"·"단가미등록" 오탐 수정** — 여러 업무명을 합칠 때 자재 사용량 집계가
   전체 의뢰서를 잘못 훑어 다른 업무명 자재까지 섞이던 버그
4. **거래명세서 Excel "구분자 문구" 행 삽입 기능 신규** — 자료와 무관하게 사용자가 직접 입력하는
   순수 캡션 행(품명~금액 병합). **DB 스키마 변경 있음**(`거래명세서_품목.구분자` 컬럼 신규)
5. **구분자 행을 "품명이력" 자동 재사용 대상에서 제외** — 다음 미리보기 때 엉뚱한 위치(하단)에
   자동으로 다시 나타나던 문제 수정

## 1단계 — 코드 파일 복사

로컬 PC의 아래 파일 3개를 사무실 PC의 같은 경로(`scripts/`)로 덮어씁니다.

- `scripts/billing.py`
- `scripts/api.py`
- `scripts/init_db_mariadb.py`

(프론트엔드 파일은 전부 로컬 PC 전용이라 사무실 PC에 옮길 필요 없습니다.)

## 2단계 — DB 마이그레이션 실행

사무실 PC에서:
```
python scripts/init_db_mariadb.py
```
`거래명세서_품목.구분자` 컬럼이 새로 추가됩니다(마이그레이션이 이미 있으면 자동으로 건너뜁니다 —
안전하게 반복 실행 가능).

## 3단계 — API 서버 재시작

1. 기존에 떠 있는 API 서버 창을 닫거나 Ctrl+C로 종료(포트 8001)
2. `API서버_실행_사무실PC.bat` 다시 실행
3. 브라우저에서 `http://localhost:8001/health` 접속 → 정상 응답 확인

## 4단계 — 확인 (브라우저)

1. 업무명이 2개 이상 섞인 거래처(예: 강남대성수능연구소(주) A교재+S교재)로 거래명세서 미리보기
   → 원본 표가 업무명별로 분리돼 나오고, "장수/자재사용량 불일치"·"단가 미등록" 경고가 안 떠야 함
2. 조건식 편집창 필드 목록에 "업무명"이 보이는지 확인
3. 아무 값도 안 고치고 확정 → "편집됨" 배지가 잘못 붙지 않는지 확인
4. 오른쪽 표에서 "+ 구분자 추가"·"구분자삽입" 버튼으로 문구 삽입 → 확정 → 다운로드한 Excel에서
   품명~금액이 병합된 줄로 정상 표시되는지 확인
5. 같은 거래처로 미리보기를 다시 열어 구분자가 하단에 자동으로 재등장하지 않는지 확인
