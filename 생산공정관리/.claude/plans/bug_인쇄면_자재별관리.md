# 인쇄면(양면/단면)을 거래처+업무명 단위가 아니라 용지 자재 단위로 관리해야 함

> 상태: ✅ 완료(2026-08-22) — `.claude/plans/plan_출력비_장수페이지기준_인쇄면자재별.md`로 흡수돼
> 구현·검증까지 완료(사용자가 "장수기준/페이지기준" 이슈와 같은 문제라고 지적해 하나로 병합).
> 아래 내용은 문제 발견 당시 기록으로 남겨둠 — 실제 구현 상세는 위 병합된 계획 파일 참고.

## 문제 요약

실사용 검수 중(삼성화재해상보험(주) · 계약보전(PLK)웰컴팩, 의뢰서 96315) 미리보기 화면에서
"표지출력비" 수량이 504로 나오는데 실제로는 503이어야 한다는 제보가 있었음 → 조사·재확인 결과
두 갈래로 분리됨:

1. **96315 이 건 자체는 시스템 버그가 아님** — "표지" 자재 실사용량 252는 당사 공정관리시스템
   운영자가 잘못 등록한 **원시데이터 입력 오류**이고, 실제로는 503이 맞음(사용자 확인,
   2026-08-22). 원시데이터가 정정되면 이 건은 저절로 해결됨 — 우리 쪽 계산 코드를 고칠 필요 없음.
2. **다만 별개로, 구조적인 개선 필요 사항이 드러남** — 지금 `단가마스터.인쇄면`(양면/단면)은
   거래처+업무명(+작업명) 단위로 딱 하나만 설정 가능한데, 실제로는 같은 거래처+업무명(+작업명)
   안에서도 용지 자재 종류별로 양면/단면이 다를 수 있음(예: 내지는 양면, 표지는 단면). 지금
   구조로는 이런 경우를 표현할 방법이 없어, 향후 비슷한 사례(자재별로 인쇄면이 섞인 거래처)가
   생기면 이번과 같은 오차가 반복될 수 있음.

**이번에 작업한 "공정별 단가 청구" 기능(`.claude/plans/plan_공정별단가청구.md`)과는 무관** — 출력비
계산 코드는 그 작업에서 손대지 않았음. 2026-08-17에 도입된 기존 인쇄면 배율 로직의 구조적 한계임.

   인쇄면 배율을 개별 적용하도록 변경
