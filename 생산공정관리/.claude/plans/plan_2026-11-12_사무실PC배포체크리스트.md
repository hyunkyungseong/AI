## 3단계 — API 서버 재시작

1. 사무실 PC에서 기존에 떠 있는 API 서버 창을 닫거나 Ctrl+C로 종료(포트 8001)
2. `API서버_실행_사무실PC.bat` 다시 실행
3. 브라우저에서 `http://localhost:8001/health` 접속 → 정상 응답 확인

## 4단계 — 확인 (브라우저)

1. 조(작업구분)가 없는 거래처 건으로 거래명세서 미리보기를 열고, 오른쪽 표 위 "시트 상단 업무명(B12)" 칸에
   업무명을 입력해 확정
2. 발행 목록에서 그 건의 엑셀을 내려받아 확인
   → 예상 결과: 거래명세서 시트 상단(B12)과 첫 장 **"요청내용" 표지 "품목"**에 둘 다 입력한 값이 나와야 함
3. B12를 비워두고 확정한 건, 조가 여러 개인 거래처(BC카드 등) 건은 기존과 똑같이 나오는지 확인(회귀 없음)

❌ 오류 시: 빨간색 오류 메시지를 캡처하거나 내용을 그대로 복사해서 알려주세요.
되돌리기가 필요하면 1단계에서 백업한 `api.py.bak_20261112`를 `api.py`로 이름을 바꾸고 3단계(재시작)만 다시 하면 됩니다.
