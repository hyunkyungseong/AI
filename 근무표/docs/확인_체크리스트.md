## ✅ 확인 완료 항목 (엑셀 분석으로 파악됨)

- [x] **근무 코드**: 빈칸(출근) / OFF(휴무) 두 가지만 사용
- [x] **파출 코드**: `-`(불필요) / `1`(1명 투입)
- [x] **조 구성**: 주간조 6명 + 야간조 6명 (조리사 별도)
- [x] **근무 시간**: 주간/야간 고정시간 출퇴근 (별도 기록 불필요)
- [x] **파출 자동 집계**: 월말에 파출 필요 총 횟수 합산 표기
