## Context

`docs/API규격서_생산공정관리시스템전달용.md`(당사 생산공정관리시스템 개발 담당자에게 전달할
연동 문서)를 검토하다가, 문서 최종 갱신일(2026-07-20) 이후 실제 코드(`scripts/api.py`)에는
반영됐지만 문서에는 빠져 있던 필드 2종을 발견해 반영했다. 생산공정관리시스템은 아직 이 API로
실시간 데이터를 보내고 있지 않고(테스트 중), 테스트가 어느 정도 끝나면 실시간 연동을 시작할
예정이라고 함(2026-08-30 사용자 확인).
