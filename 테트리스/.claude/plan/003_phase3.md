# Phase 3 — 경쟁 & 소셜

## 구현 항목

### 1. 로컬 리더보드
- `localStorage`에 상위 10개 기록 저장 `{ name, score, lines, mode, date }`
- 게임 종료 시 닉네임 입력 → 순위 표시
- 모드별 리더보드 분리 (마라톤 / 스프린트 / 울트라)

### 2. 스킨 & 테마
- CSS 변수 기반 테마 3종:
  - `cyber` — 현재 네온 사이버펑크 (기본)
  - `classic` — 밝은 게임보이 스타일
  - `retro` — 80년대 아케이드 CRT 느낌
- 설정 버튼 → 테마 패널, 선택 시 `<body data-theme="...">` 변경
- 선택값 `localStorage`에 저장

### 3. 멀티플레이 (백엔드 필요)
- **서버**: `server.js` — Node.js + `ws` 라이브러리 WebSocket 서버
- **클라이언트**: `tetris.js`에 네트워크 레이어 추가
- 기능:
  - 방 생성 / 방 코드로 참여
  - 줄 클리어 시 가비지 라인 상대에게 전송
  - 실시간 상대 보드 미니 표시
  - 게임오버 시 승/패 판정

## 수정 대상 파일
- `index.html` — 리더보드 패널, 테마 설정 버튼, 멀티 UI
- `style.css` — 테마 CSS 변수, 리더보드 테이블
- `tetris.js` — 리더보드 로직, 테마 적용, WebSocket 클라이언트
- `server.js` (신규) — WebSocket 서버, 방 관리, 가비지 전송 로직

## 기술 의존성
- `ws` npm 패키지 (멀티플레이)
- Node.js 서버 실행 환경

## 검증 방법
- 리더보드: 게임오버 → 닉네임 입력 → 순위 진입 확인
- 테마: 3종 전환 후 새로고침해도 유지 확인
- 멀티: 두 탭에서 접속 → 양방향 가비지 전송 확인
