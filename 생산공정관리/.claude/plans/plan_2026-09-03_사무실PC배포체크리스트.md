1. 사무실 PC에서 기존에 떠 있는 API 서버 창을 닫거나 Ctrl+C로 종료(포트 8001)

3. 브라우저에서 `http://localhost:8001/health`(또는 사무실 PC 접속 주소) 접속 → 정상 응답 확인
