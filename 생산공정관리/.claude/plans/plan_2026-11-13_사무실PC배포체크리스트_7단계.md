## 문제가 생기면 (되돌리기)

| 증상 | 조치 |
|---|---|
| 3단계에서 오류 | 아직 아무것도 바뀌지 않은 상태에 가까움 — 캡처 전달 후 대기 |
| 4단계 이후 API 서버가 안 켜짐 | `scripts`의 4개 파일을 `.bak_20261114`에서 원래 이름으로 되돌리고 API 서버 재시작 |
| 5단계 이후 화면 오류 | 화면 창 닫기 → 새 `frontend`를 `frontend_failed_20261114`로 이름 변경 → `frontend_old_20261114`를 `frontend`로 이름 되돌림 → `웹화면_실행_사무실PC.bat` 실행(조립 결과까지 통째로 보관돼 있어 재조립 불필요) |

- 3단계에서 추가된 DB 칸·`시스템설정` 표는 **되돌리지 않아도 됩니다.** 예전 코드는 이 칸을 쓰지 않아서 그대로 남아 있어도 영향이 없습니다.
- ❗ **새 화면 + 예전 서버 조합은 동작하지 않습니다.** 새 화면은 첫 화면을 그릴 때 새 서버 기능(`/내정보`)을 부르기 때문에, 서버만 되돌리면 업무 화면이 오류가 납니다. 서버를 되돌릴 때는 **화면도 반드시 함께** 되돌려 주세요.
- 반대로 **새 서버 + 예전 화면** 조합은 동작합니다(4단계를 마치고 5단계 전까지가 이 상태). 그래서 화면 반영(5단계)에서 문제가 생기면 화면만 되돌려도 됩니다.
