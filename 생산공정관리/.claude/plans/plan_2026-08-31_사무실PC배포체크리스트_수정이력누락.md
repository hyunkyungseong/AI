> 남은 미배포 항목 없음. (상세: `.claude/plans/bug_수정이력_신규규칙동시확정_품목변경누락.md`)

## 오늘 수정 내용 요약

조건식(청구품목규칙)을 그 거래처+업무명 조합에 대해 **처음 만드는 동시에** 품목 수량·단가 등을
직접 고쳐서 확정하면, "원본 vs 최종 비교" 팝업의 수정이력에 공급가액·부가세·합계 변경만 남고
정작 수량 변경 자체는 기록이 안 되던 버그를 수정. `scripts/api.py` 한 파일만 변경, **DB 구조
변경(마이그레이션) 없음**.

## 1단계 — 코드 파일 복사

로컬 PC의 아래 파일을 사무실 PC의 같은 경로(`scripts/`)로 덮어씁니다.

- `scripts/api.py`

## 2단계 — API 서버 재시작

1. 기존에 떠 있는 API 서버 창을 닫거나 Ctrl+C로 종료(포트 8001)
2. `API서버_실행_사무실PC.bat` 다시 실행
3. 브라우저에서 `http://localhost:8001/health` 접속 → 정상 응답 확인

마이그레이션 스크립트 실행은 필요 없습니다(DB 스키마 변경 없음).

## 3단계 — 확인 (브라우저)

조건식이 한 번도 저장된 적 없는 거래처+업무명 조합으로 거래명세서 미리보기를 열어, 조건식을
새로 만들면서 동시에 수량을 고쳐 확정 → "원본 vs 최종 비교" 팝업의 수정이력에 "수량" 항목이
정상적으로 남는지 확인.
