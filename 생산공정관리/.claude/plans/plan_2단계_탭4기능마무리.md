## ✅ 단가 구조 확정 (2026-06-21 완료)

- 계약명은 운영통계자료에 없음 → **업무명 + 작업명(=업무명상세) 조합으로 계약 단위 대체**
- 단가 구별 기준: **작업명(업무명상세)** — 동일 거래처·업무명이어도 작업명이 다르면 단가가 다를 수 있음
- 관리 방식: **거래처 기본단가 + 예외단가** (업무명·작업명 지정)

### 확정된 DB 구조

**거래처마스터** (단가 필드 제거, 기본정보만)
```
거래처명(PK), 사업자등록번호, 수신이메일, 비고, 등록일, 수정일
```

**단가마스터** (신규 테이블)
```
id(PK), 거래처명, 업무명(NULL=거래처 전체 기본), 작업명(NULL=업무명 단위 기본),
출력단가, 봉입단가, 추가봉입단가, 용지제작단가, 봉투제작단가, 삽지제작단가, 비고, 등록일, 수정일
UNIQUE(거래처명, 업무명, 작업명)
```

**단가 조회 fallback 순서:**
1. 거래처명 + 업무명 + 작업명 (가장 구체적인 예외단가)
2. 거래처명 + 업무명 + 작업명=NULL (업무명 단위 기본단가)
3. 거래처명 + 업무명=NULL + 작업명=NULL (거래처 전체 기본단가)
4. 없으면 → 예상공급가액 빈 칸 표시
