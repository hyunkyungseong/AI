## 🔄 작업 프로세스 (스크립트 실행 순서)

> 맞춤약관 PDF 한 건을 만드는 전체 흐름입니다.
> **05, 06만 반복 실행**하면 됩니다 (01~04는 최초 1회).

```
[최초 1회 — 준비 작업]

STEP 1  scripts/01_format_xml.py
        원본 HWP XML → 줄바꿈 정렬된 formatted XML
        입력: C:\D드라이브\다운로드\..._약관.xml
        출력: data/..._약관_formatted.xml

STEP 2  scripts/03_validate_toc.py          ※ 새 약관 파일 적용 시 필수
        엑셀 조건표 목차명 ↔ XML 텍스트 100% 일치 검증
        입력: data/조건표.xlsx + data/..._formatted.xml
        출력: docs/results/validate_result.txt

STEP 3  scripts/04_build_range_map.py       ※ 새 약관 파일 적용 시 필수
        특약별 XML 범위 탐색 → 담보코드 매핑
        입력: data/조건표.xlsx + data/..._formatted.xml
        출력: work/range_map.json + docs/results/range_map_result.txt

────────────────────────────────────────────────
[매번 실행 — 가입자별 맞춤약관 생성]

STEP 4  scripts/05_generate_맞춤약관.py     ★ 담보코드 목록 수정 후 실행
        가입자 담보코드 입력 → 미가입 특약 삭제 → 맞춤약관 XML 생성
        입력: work/range_map.json + data/..._formatted.xml
        출력: output/맞춤약관_출력.xml

STEP 5  scripts/06_generate_pdf_com.py
        한컴오피스 COM 자동화로 XML → PDF 변환
        입력: output/맞춤약관_출력.xml
        출력: output/맞춤약관_출력.pdf

────────────────────────────────────────────────
[선택 — 내용 확인용]

TOOL    scripts/임시_weasyprint_pdf생성.py
        XSLT 변환 → HTML → 브라우저 오픈 (내용 육안 확인용)
        ※ 서식은 원본과 다를 수 있음. 최종본 아님.
```
