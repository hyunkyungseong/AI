# 다음 작업 메모: 비교 창에서 수정된 행 강조 + 팝업 창 이동

> 상태: 📝 요청 접수만 함. 분석·계획 전(2026-11-15 대화 마무리 시 사용자 요청)
> 진행 방식: 새 대화에서 **코드 분석(Read-only) → 계획서 작성 → 승인(ExitPlanMode) → 한 단계씩** 진행

## 요청 1: 수정된 행을 쉽게 알아보게
- 대상 화면: 거래명세서 관리의 **"발행요청목록", "발행완료"** 탭에서 여는 미리보기(원본/최종 비교) 창
- 원하는 것: **최종본에서 수정된 행**을 사용자가 한눈에 알아볼 수 있게 표시
- ⚠️ 사용자가 "첨부된 이미지"를 언급했지만, 마무리 메시지에는 이미지가 붙어 있지 않았음
  - 새 대화에서 **화면 캡처를 다시 받아** 어떤 창인지 확인할 것
- 분석 출발점(추정, 확인 필요)
  - `frontend/components/InvoiceHistoryDialog.tsx`: "편집됨/원본" 배지를 누르면 뜨는 원본/최종 비교 창(읽기 전용)
  - 수정이력 표시는 `frontend/lib/auditLog.ts`와 공용
- 정할 것: "수정된 행"의 기준을 사용자와 정해야 함
  - 후보 1: 사람이 고친 수정이력이 있는 행
  - 후보 2: 조건식 적용 결과(기준)와 최종을 비교해 다른 행
  - 후보 3: 그 밖의 기준
  - 정한 뒤 표시 방법(행 배경색, 바뀐 칸 강조, 이전 값 표시 등)을 고를 것
