# 신규 공정 확장(씰링/압착·에폭시·코팅·제본·중철) — "건수" 의미 재정의 필요

> 상태: ⏳ 대기 중 — 이슈만 기록, **다음 새로운 세션(컨텍스트)에서 조사·설계 착수 예정**(사용자
> 지시, 2026-08-18). 이번 세션에서는 데이터 존재 여부만 가볍게 확인했고 코드 조사·구현은
> 하지 않음.

## 문제 요약 (사용자 설명)

`data/운영통계자료.xlsx`에 **씰링(압착)·에폭시·코팅·제본·중철** 공정이 추가되면, 지금 시스템이
당연하게 가정하고 있는 "**건수 = 봉입건수**"라는 등식이 깨진다. 이 공정들은 **봉투 자재를 쓰지
않는 작업**이기 때문에, "건수" 컬럼 값이 있어도 그게 봉입(봉투에 넣은) 건수를 뜻하는 게 아니다.

기존 로직(청구페이지 계산, 봉입비 계산, 반제품여부 판정 등 — `scripts/billing.py`·
`scripts/data_transform.py`)은 전부 "건수=봉입건수"를 전제로 짜여 있어서, 이 공정들이 실제 청구
계산 경로를 타면 잘못된 금액(봉입비를 청구하면 안 되는데 청구되거나, 반대로 실제로 청구해야
할 값이 빠지는 등)이 나올 위험이 있다.

## 이번 세션에서 가볍게 확인한 것 (로컬 MariaDB `운영통계자료` 기준)

키워드로 `작업명`·`작업내역서`를 검색한 결과 — **일부는 이미 데이터가 존재함**(2026-08-17
`plan_2026-08-17_사무실PC배포체크리스트.md`에 "운영통계자료에 데이터가 아직 없어 보류"로
적어뒀던 것과 달리, 이미 들어와 있는 공정이 있으므로 이 메모는 갱신 필요):

| 키워드 | 건수 | 비고 |
|---|---|---|
| 씰링 | 97건 | 현대해상 "분납 안내(씰링)", 국민건강보험공단 "지역고지서(씰링)" 등 |
| 압착 | 0건 | 아직 없음 |
| 에폭시 | 4건 | 소수 존재 |
| 코팅 | 0건 | 아직 없음 |
| 제본 | 2,287건 | 대부분 강남대성수능연구소 "...컷팅-제본-발송" 작업명 안에 포함된 형태 — 독립 공정이라기보단 기존 작업명 문자열의 일부일 수 있어 실제 영향 여부는 재확인 필요 |
| 중철 | 18건 | 소수 존재 |

**씰링 샘플에서 발견한 의심 정황**: 현대해상 "분납 안내(씰링)"·국민건강보험공단 "지역고지서(씰링)"
샘플 행 여러 건에서 **`건수` == `장수`가 정확히 일치**(예: 37=37, 9,899=9,899). 일반적인 봉입
작업은 장수(인쇄 매수)와 건수(봉입 건수)가 다른 게 정상인데, 이 두 값이 항상 같다는 건 "종이
한 장 = 발송 한 건"(봉투 없이 그 자체로 접어 봉함하는 셀프메일러 방식)이라는 사용자 설명과
정확히 들어맞음 — 즉 이 "건수"는 봉입건수가 아니라 단순 처리/발송 건수일 가능성이 높음.

**확인 안 한 것(다음 세션 몫)**: 이 거래처들(현대해상 씰링 건, 국민건강보험공단 등)이 지금
**이미 정상적으로 청구되고 있는지, 아니면 이미 잘못 계산되고 있는지** — 단가마스터에 이 작업에
대한 단가가 등록돼 있는지, 등록돼 있다면 봉입비가 잘못 청구되고 있지는 않은지 확인 필요.

## 다음 세션 시작 시 할 일 (제안 순서)

1. **영향 범위 코드 조사**: `건수`를 읽어 "봉입"으로 취급하는 모든 지점 찾기
   - `scripts/billing.py` — 봉입비(M) 계산, 반제품여부(봉입건수=0) 관련 로직
   - `scripts/data_transform.py`·`scripts/preprocess.py` — 청구페이지 계산 3가지 경우 중
     "건수" 기반 분기가 있는지
   - `scripts/app.py`(Streamlit) — "봉입건수" 표시·합계 로직
2. **실사용 영향 확인**: 위 표의 씰링·에폭시·제본·중철 거래처들이 실제로 거래명세서 발행까지
   갔었는지(`거래명세서_의뢰서`·`거래명세서_품목` 이력 조회), 갔었다면 금액이 맞았는지 사용자와
   함께 재검토
3. **"건수"의 새 의미 정의**: 공정별로 건수가 무엇을 뜻해야 하는지(예: 씰링류는 "처리건수"로
   보고 봉입비 계산에서 제외, 자재 사용량 기준으로 전환 등) 사용자 확정 필요 — 2026-08-17에
   이미 출력비·봉입비를 "자재사용량 기준"으로 전환한 선례(`.claude/plans/plan_단가마스터_자재명정규화.md`,
   `docs/CHANGELOG.md` 2026-08-17 항목)가 참고가 될 수 있음(자재가 없는 공정은 그 접근 자체를
   그대로 못 쓰므로 다른 기준 필요)
4. 계산 로직 변경 방향이 정해지면 이 파일을 `plan_기능명.md` 정식 구현 계획으로 갱신
