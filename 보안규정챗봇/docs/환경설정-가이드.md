## 🔄 최초 실행 순서 (새 PC 세팅 시)

```
1. Python 설치 확인
   python --version

2. 패키지 설치
   pip install -r requirements.txt

3. 문서 처리 (벡터 저장소 생성) — 최초 1회 또는 문서 추가 시
   python ingest.py
   ※ 최초 실행 시 한국어 임베딩 모델 자동 다운로드 (~500MB)

4. 서버 실행
   python app.py

5. 브라우저 접속
   http://localhost:5000
   또는 사내망에서 http://[서버IP]:5000
```
