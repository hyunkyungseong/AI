# 상단 GNB(전역 내비게이션) 배치

> 상태: ✅ 완료(2026-08-12, 같은 날 후속 세션) — 최상위 탭 5개를 대분류 3개(통계 분석/거래명세서
> 관리/거래처 마스터)로 묶고, 대분류 클릭 시 상단 2번째 줄에 하위탭이 항상 표시되는 2단 구조로
> 개편 완료. 사용자가 로컬 PC 실제 화면에서 5가지 테스트 항목 전부 정상 동작 확인 완료.
> 이어서 발행요청목록·발행완료 탭 "업무명" 칸 가독성 개선(말줄임+툴팁)도 같은 세션에서 함께 완료.
> 상세 내용은 `docs/CHANGELOG.md` 2026-08-12 항목 참고. 이 플랜 파일은 보관용으로 남겨둠.

## 최종 확정된 구조
- 1줄(대분류, 항상 표시): [통계 분석] [거래명세서 관리] [거래처 마스터]
- 2줄(하위탭, 클릭한 대분류에 따라 내용이 바뀌며 항상 표시):
  - 통계 분석 → 작업 현황 요약 / 거래처별 현황 / 담당자별 현황
  - 거래명세서 관리 → 미발행 목록 / 발행요청목록 / 발행완료
  - 거래처 마스터 → 거래처관리 / 단가관리 / 담당자관리
- 각 대분류는 마지막으로 보던 하위탭을 독립적으로 기억
- 왼쪽 세로 사이드바 방식은 각 화면 왼쪽의 검색 필터 패널과 자리가 겹쳐 제외(사용자 확정)
