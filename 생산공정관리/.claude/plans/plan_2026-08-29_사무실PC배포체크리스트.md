# 2026-08-29 사무실 PC 배포 체크리스트 — 재료비 무상 + 품명이력 덮어쓰기

> 상태: ✅ 배포 완료(2026-08-29) — 사용자 브라우저 확인 완료

## 오늘 작업 요약
1. **재료비(용지·봉투·삽지) "무상(고객사 제공)" 체크박스** (`.claude/plans/plan_재료비_무상표시.md`) — 고객사가 자재를 직접 제공해 무상인 항목을 "단가 등록 누락"으로 오판해 경고를 띄우던 문제 수정. 단가마스터에 체크박스 신규(대부분 유상이라 기본 미체크), 자재별 단가와 양방향으로 모순 방지
2. **거래명세서품명이력 "확정 시마다 덮어쓰기"로 변경** — 새 행 추가(수동입력)를 잘못 넣고 확정한 뒤, 다음에 전부 지우고 확정해도 예전 값이 계속 자동완성으로 재등장하던 문제 수정. 이제 확정할 때마다 그 거래처 이력을 이번 확정분으로 통째로 교체

## 1단계 — 코드 파일 복사
로컬 PC의 아래 3개 파일을 사무실 PC의 같은 경로(`scripts/`)로 덮어씁니다.

- `scripts/api.py`
- `scripts/billing.py`
- `scripts/init_db_mariadb.py`

**프론트엔드 파일은 복사 불필요** — 화면은 로컬 PC의 Next.js가 그대로 담당하고, `frontend/.env.local`의 `FASTAPI_URL`로 사무실 PC를 가리켜 씁니다.

## 2단계 — DB 마이그레이션 실행
사무실 PC에서:
```
cd 프로젝트폴더
python scripts/init_db_mariadb.py
```
→ 콘솔에 아래 3줄이 뜨면 성공(순서는 다를 수 있음):
```
마이그레이션: 단가마스터.용지제작무상 컬럼 추가 완료(기존 행 전부 0으로 채워짐)
마이그레이션: 단가마스터.봉투제작무상 컬럼 추가 완료(기존 행 전부 0으로 채워짐)
마이그레이션: 단가마스터.삽지제작무상 컬럼 추가 완료(기존 행 전부 0으로 채워짐)
```
(다른 마이그레이션은 전부 "이미 존재 (건너뜀)"으로만 나와야 정상)

## 3단계 — API 서버 재시작
1. 기존에 떠 있는 API 서버 창을 닫거나 Ctrl+C로 종료(포트 8001)
2. `API서버_실행_사무실PC.bat` 다시 실행
3. 브라우저에서 `http://localhost:8001/health` 접속 → 정상 응답 확인

## 배포 후 확인할 것 (브라우저)

### 재료비 무상
1. 단가마스터에서 삼성화재해상보험(주)·모니터링안내장 "수정" 열기 → "봉투제작단가" 입력칸 아래 "무상(고객사 제공)" 체크박스가 보이는지
2. 체크 후 저장 → 의뢰서 97531로 "거래명세서 요청" 미리보기 열기 → "봉입자재비(모니터링안내장) — 3" 단가미등록 경고가 사라졌는지
3. "자재별 단가" → "+ 자재단가 추가" 열기 → "항목" 드롭다운에 "봉입자재비(봉투)"가 안 보이는지
4. 이미 자재별 단가가 등록된 다른 항목(예: 출력자재비)의 대응 무상 체크박스가 비활성화 + 툴팁으로 안내되는지

### 품명이력 덮어쓰기
5. 아무 거래처에서 "거래명세서 요청" 미리보기 → "새 행 추가"로 임의 품명 입력 → 확정
6. 그 거래명세서 취소 → 같은 조건으로 다시 미리보기 열기 → 방금 입력한 품명이 자동 반영되는지(정상 동작 확인)
7. 다시 확정 화면 열어 그 자동반영된 행을 삭제 → (수동입력 0건 상태로) 확정
8. 취소 후 다시 미리보기 열기 → 이번엔 그 품명이 더 이상 자동 반영되지 않는지(이번 수정으로 해결된 부분)
