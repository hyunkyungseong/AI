## 📌 프로젝트 개요
- **프로젝트명:** 작업현황 대시보드 생성
- **업종:** DM(다이렉트메일) 및 교재 제작
- **목적:**
  1. 공정관리시스템 자료(`운영통계자료.xlsx`)를 활용해 통계 생성
  2. 거래처별 출력·봉입 작업 현황을 시각화
  3. 웹 환경에서 대시보드를 팀 내부에서 볼 수 있게 함
- **주요 시각화 항목:**
  - 거래처별 작업 현황 (출력, 봉입)
  - 전월 대비 현황
  - 전년 동월 대비 현황
  - 담당자별 작업 현황
- **원본 데이터:** `data/운영통계자료.xlsx`
- **결과물 전달 대상:** 우리 팀 내부
- **팀 규모:** 2 ~ 5명
- **주 사용자 유형:** 비개발자 (코딩을 잘 모름)
