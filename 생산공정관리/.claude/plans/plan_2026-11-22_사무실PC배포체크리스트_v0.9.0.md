## 문제가 생기면 (되돌리기)
| 증상 | 조치 |
|---|---|
| 2단계 이후 API 서버가 안 켜짐 | ① `scripts`에 `version.py`가 있는지 먼저 확인(없으면 USB에서 복사 후 재시작) ② 그래도 안 되면 `api.py.bak_버전도입전`→`api.py`, `data_transform.py.bak_버전도입전`→`data_transform.py`로 되돌리고 재시작 bat 실행 |
| 3단계 이후 화면 오류 | 화면 창을 닫습니다. → 새 `frontend`를 `frontend_failed_v0.9.0`으로 이름을 바꿉니다. → `frontend_old_버전도입전`을 `frontend`로 되돌립니다. → `웹화면_실행_사무실PC.bat`을 실행합니다. |
| 화면에 주황색 `서버 ?` | API 서버가 꺼졌거나 옛 서버입니다. 1·2단계를 다시 확인합니다. |

- **서버·화면을 따로 되돌려도 다른 기능은 동작합니다.** 새 화면 + 옛 서버면 배지만 주황색 `서버 ?`로 보이고, 새 서버 + 옛 화면이면 배지만 안 보입니다.
