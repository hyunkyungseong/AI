# 플랜: 고객 제출용 명세서

> 작성: 2026-11-22 | 상태: ✅ 완료 (2026-11-22 — 0~7단계 + 사무실 PC 배포 v0.10.0). 후속: 예외 백자료 담당자 첨부 기능(별도 계획 예정)


## Context (왜 하는가)
- 일부 거래처(예: 농협카드)는 회사 내부용 거래명세서와 별도로 **고객에게 보내는 명세서**가 따로 필요함. 내부용 줄들을 묶어서 줄 수를 줄이고 품명을 바꾼 형태이며, 한 줄일 수도 여러 줄일 수도 있음
  - 근거: `output/20260630_농협카드(6월 작업분) - 계산서 발행용.xlsx`의 `1. 거래명세서`
- 매수별 분리 청구는 **취소**(KNOWLEDGE "주요 결정사항"에 기록 완료). 예외 백자료는 나중에 "첨부" 기능으로 별도 진행
- **사용자 확정 사항**
  - 미리보기에서 "확정"을 누르면, 고객 제출용 사용 거래처는 고객용 편집창이 **이어서** 뜸
  - 그 외 거래처는 지금처럼 바로 발행요청목록으로 이동
  - 고객용 편집은 지금 편집창처럼 여러 줄 편집 가능
  - 고객용 **합계가 내부용과 다르면 저장 막음**
  - 수정이력은 내부용 단계에서만 남기고, 고객용 단계에서는 **금액이 바뀌지 않게** 함 → 수량·단가·금액은 사람이 입력하지 않음
  - 묶음은 거래처+업무명별로 저장해 **다음 확정 때 자동 적용**

## 핵심 설계 (비유: 내부용 줄은 "물건", 고객용 줄은 "상자" — 물건을 상자에 담기만 하고 물건 값은 못 바꿈)
- 고객용 줄 하나 = { 품명·규격·비고(입력), 담긴 내부용 줄 목록 }
- 금액은 담긴 줄의 합계로 자동 계산
- 수량·단가는 담긴 줄의 단가가 전부 같을 때만 "수량 합계·그 단가"로 자동 표시하고, 다르면 빈칸
- **"나머지 전부" 상자**를 하나 둘 수 있음: 어느 상자에도 안 담긴 줄을 모두 받음(한 줄 요약 거래처용, 다음 달 새 품목이 생겨도 자동 흡수)
- **저장 막는 조건**: 어느 상자에도 안 담긴 내부용 줄이 있을 때 → 결과적으로 "합계가 다르면 막음"과 같음
- **서버는 화면이 보낸 금액을 믿지 않음**: 화면은 "어느 줄을 어느 상자에" 정보만 보냄. 서버가 확정 직전 최종 줄로 금액을 직접 합산하고, 전부 정확히 한 번씩 담겼는지·합계가 같은지 다시 확인. 틀리면 400 오류로 전체 거부
- **한 번에 저장**: 내부용 확정 + 고객용 줄 + 묶음 규칙을 같은 요청·같은 트랜잭션(`POST /거래명세서요청`의 기존 with 블록, `scripts/api.py:2839-2994`)에서 저장 → 2단계 창을 닫으면 아무것도 확정되지 않음
- **줄 매칭 키**: 다음 달 자동 적용 때는 기존 관례 `_품목_매칭키` = (코드, 표시품명, 조)(`api.py:2454`)를 재사용. 같은 키가 여러 개면 모두 같은 상자로 감
- **엑셀**: 다운로드 시 맨 앞에 `고객 제출용` 시트 추가(통합시트를 끼운 뒤 `insert(0)`, `api.py:1401` 뒤)
  - 시트 하단 공급가액·세액·합계는 내부용과 **같은 저장값**을 사용(직접입력 금액 포함)
  - **표지("요청내용")는 지금과 동일**하게 내부용 기준(비고 "시트참조"도 내부용 첫 시트를 가리키게 유지)
- **부분취소**: 남은 줄로 다시 확정되는 기존 흐름(`api.py:3336-3337` 직후)에서 저장된 묶음을 다시 적용
  - 다 담기면 고객용 줄 교체
  - 안 맞으면 그 건에 "고객용 재편집 필요" 표시 + 고객용 줄 삭제
  - 점검만 모드는 기존처럼 롤백되어 부작용 없음
- **재편집**: 발행요청목록(미발행 건)에서 "고객용 편집" 버튼으로 같은 편집창을 다시 엶. 금액은 원래 못 바꾸므로 안전. 재편집 필요 건은 다시 맞출 때까지 **엑셀 다운로드 차단**(안내 문구)
